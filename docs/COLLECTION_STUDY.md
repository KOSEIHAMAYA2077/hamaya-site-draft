# 制作の棚・非公開比較

2026-10-03 UTCに作成した独立比較案です。既存ホームと5つの方向性、write、検索の実装は保持しています。主案への採用と作品・記事の掲載は本人の判断を待ちます。

## 使い方と構成

作品名を曲線の周りに置き、選んだ制作を脇の紙面で読みます。立体は静止した独自SVGで、文字の下に紙面を敷き、装飾がクリックを受け取らないようにしています。新しいイントロ、無限アニメ、外部画像、外部フォント、3Dランタイムはありません。

| 導線               | 現在の表示と動作                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------ |
| 作品を選ぶ         | 検証済み6件の名前から選択。同じ読み物面がすぐ切り替わり、選択をURLのfragmentへ残します。                     |
| 関連する学び・雑記 | 本人が明示して結び付けた公開記事だけを表示。現在は関係が未確認なので空状態と一覧・記録を書く入口です。       |
| 次に触るもの       | 確認済みGitHubのコードを別タブで開くか、別の作品を選べます。本人の制作予定や制作順を示すものではありません。 |

モバイルでは選んだ読み物面へ移動し、フォーカスもその面へ渡します。デスクトップでは作品名にフォーカスを保ちます。JavaScriptがない場合は6件の読み物を続けて表示し、通常のfragmentリンクで開けます。

既存ホームは導入と作品・記録への入口を大きく扱う案です。制作の棚は、作品の名前と読む面を並べ、どれかを開いてから記録やコードへ進む案です。比較画像は同じ1280px幅と812px高さで撮影しています。比較案だけに掲載候補のデータがあるため、純粋な装飾だけの比較ではありません。

## 使用した情報

[既存資料の移植候補](MIGRATION.md)で検証済みの6つの公開GitHubリポジトリを、IDとURLの許可リストで限定します。元の作品下書きは変更していません。

- 使うのは作品名、GitHub API由来の説明5件、確認済みリポジトリURLです。説明は原文のまま、出典を付けて表示します。
- `one-board-incremental`の説明は元APIでnullのため表示しません。
- 準備日を制作日として使いません。日付、状態、本人の役割、本文、画像、未確認の実績や関係は表示モデルへ渡しません。
- 旧Cyberpunk雑記との制作上の関係は未確認のため、題・本文をこの比較案へ転用していません。

関連記録は [src/data/work-records.json](../src/data/work-records.json) に作品IDと記事IDの対応を記入します。現在は空です。本人が関係を確認してから、たとえば次の形式で指定できます。記事側の `draft: true` は比較でも除外し、安全なIDから生成済みの詳細ページだけへリンクします。

```json
{
  "import-typeandsummon": ["confirmed-note"]
}
```

この例のIDや文章を本人の記録として追加してはいません。

## ローカルで再表示する

通常buildでは `/compare/collection/` を生成しません。作品候補の情報は通常ページ・共有JS・JSONへ入りません。明示した比較buildの専用HTMLだけに表示します。

```sh
LOCAL_COMPARISON=1 npm run build
LOCAL_COMPARISON=1 npm test
npx astro preview --host 127.0.0.1 --port 4334
```

`http://127.0.0.1:4334/compare/collection/` を開きます。別の既存プレビューと同時に使う場合は、独立したコピーでbuildします。プロジェクト用baseは同じbuildとtestに `BASE_PATH=/hamaya-site-draft` を添えます。

比較後は `npm run build` で通常の成果物へ戻ります。比較フラグは認証ではありません。比較用 `dist` を公開・共有する判断は本人待ちです。Pagesや公開workflowは作成していません。
