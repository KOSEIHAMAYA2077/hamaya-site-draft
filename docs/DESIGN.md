# 明るい、自分用の制作室

宣伝のための実績一覧より、つくったものや考えたことを日々残せる場所を優先します。作品・学びと雑記・自己紹介への導線を常に置き、トップから内容の一覧へすぐ進めます。

## 比べられる方向性

| 方向         | 使い方と表情                                                                         |
| ------------ | ------------------------------------------------------------------------------------ |
| 静かな軌道   | 現在のホーム。銀色の曲線と広い本文面で、読むことを中心にする基準案                   |
| 光の制作室   | 立体の明暗差と小さい鮮やかな色を強めた対案。同じ抽象物を「銀色／光の線」で切り替える |
| 円のある紙面 | 図面と重なる円による、落ち着いた文章中心の比較案                                     |
| やわらかな場 | 銀色のリボンと流れる配置を試す比較案                                                 |

`/directions/` から、同じ導線と空状態を持つ4案を開けます。採用の最終判断は本人が見てから行います。比較案は本番の主ナビには加えていません。

## 色と日本語

オフホワイトの面とグラファイトの文字を基本に、青緑を補助にします。光の制作室では、小さな黄緑の光と銀色の厚みを加えます。濃い色は抽象物の陰影に使い、本文面を暗くしません。

日本語の本文には十分な行間と短めの行長を設け、長い見出し・英単語・タグも折り返します。見出しでは約物を含めて釣り合いを見ます。表とコードは必要な横スクロールの枠に収め、文書全体の横スクロールを避けます。外部フォントを待たず、端末の日本語フォントで表示します。

## 抽象物ひとつの操作

光の制作室は同じ輪郭の金属面と透過した構造線を重ね、約0.6秒で質感を切り替えます。形が変わらないので、短い操作の結果を見比べられます。マウスとスクロールに対する変位は小さくし、本文の位置は動かしません。

図形は独自に組んだインラインSVGです。WebGPUや動画、外部の3Dモデル、音の読み込みを必要としません。初期状態ですぐ内容と銀色の図形を読め、JavaScriptを使えない場合もその状態を表示します。無限の描画ループを作らず、導入は1.3秒で終わります。フレーム更新は入力・スクロール・リサイズに応じた時だけです。

質感の選択はキーボードでも操作でき、選択状態を読み上げます。動きを止める設定はページを移っても保ちます。OSのreduced-motionでは導入・変位・遷移を止め、質感の選択自体は静止状態で使えます。実機のreduce=trueでの表示と厳密な低性能端末の計測は、今回の検証環境では行えていません。

参考サイトの映画的な体験全体を再現したとはしません。本人が日々読むページに合う、短い質感の操作ひとつの完成度を重視します。

## 本文を追加する仕組み

作品と記事はMarkdown、プロフィールは小さなJSONに分けます。作品には題・説明・日付・タグ・状態・任意の確認済みURLと表紙、記事には題・説明・日付・分類・タグ・本文を持たせます。

新しいファイルはCLIとローカル入力道具の両方で作れます。常に下書きで始まり、一覧にも詳細にも出ません。公開内容を確認した後で生成対象へ加えます。入力道具の文章は自動保存や外部送信をせず、Markdownとして本人が保存します。

公開作品と記事がない状態は明示します。自己紹介・写真・AtCoderは未入力のままです。掲載判断を待つ作品を実績として見せたり、本人の役割・件数・制作時期を補ったりしません。旧記事の本人の言葉は原文を保持した下書きで準備し、本人が採用を決めるまで生成ページに含めません。

## 保存と公開

独立した作業領域と専用privateリポジトリに保存します。GitHub Pages向けに静的生成とプロジェクト用baseを確認します。Pagesの有効化や外部公開は本人の判断を待ちます。
