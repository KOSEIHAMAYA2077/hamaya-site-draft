# 実験を見る — ローカル比較版

2026-10-04 UTC。`audit-static-safety` の `10f6781` から独立した `experiment-study` で追加した。「下書き本文・設定の漏出も確認」という以前の短報は、**配布物に漏出していないことを検査した**という意味。残存漏出の報告ではない。

## 置いたもの

`/compare/experiments/` は、ゲームの小さな仕組みを眺めてから触る入口。本人の作品一覧へは追加していない。「シドの試作（AI）」「本人の作品としての採用・公開は未確定」を画面に明記した。

- **動きと反応**：同じ入力に、体の傾きと荷物の遅れを重ねる。反応あり／固定で移動位置と距離は同じ。
- **移動と時間**：実際の移動量か連続時間かで、障害物の時計を進める。壁で動けないときや、手を離したときの違いを見る。

最初は自作の静止模式図と、変えること・起こること・短い操作説明だけを表示する。押したときだけ試用を作り、同時に開けるのは1つ。スマートフォンでは説明、試用ボタン、操作画面の順に並べる。未保存の本人データを受け取る機能や、外部への送信・記録の保存は追加していない。

出典・AIの役割・利用条件・コピーのhashは [EXPERIMENT_SOURCES.md](EXPERIMENT_SOURCES.md) と `src/experiments/source-manifest.json` にある。コピーは原本2試作のモデルとテスト計4ファイルだけ。原本UI、研究資料、会員PDF、画像、音声は含めない。モデルはbyte単位で保持し、今回のUIで包んだ。新しい依存パッケージは追加していない。

## 開き方と配布境界

リポジトリのルートで実行する。

```sh
LOCAL_EXPERIMENTS=1 npm run dev
```

`http://127.0.0.1:4321/compare/experiments/` を開く。フラグがある間だけ、ホームなどのローカル執筆入口の隣に「実験を見る」が出る。

静的版は以下で確認する。

```sh
npm run build:experiments
LOCAL_EXPERIMENTS=1 npm test
npm run preview
```

GitHub Pagesのプロジェクト用baseを確かめる場合は、build・test・previewに同じ `BASE_PATH=/hamaya-site-draft` を付ける。現在の公開0件では実験buildは13ページ。`LOCAL_COMPARISON=1` も併用すると既存の比較2案を含む15ページになる。

実験はdevでもbuildでも **`LOCAL_EXPERIMENTS=1` のときだけ**登録する。通常の `npm run build` は5ページで、実験ルート、iframe用のモデル・コード、実験の入口を含めない。`LOCAL_STUDIO=1` や `LOCAL_COMPARISON=1` だけでは新しい実験は入らない。配布用にはローカル用フラグを外してbuildし直す。これらのフラグとnoindexはアクセス制限ではない。

## 試用の隔離と停止

iframeのsandboxは `allow-scripts` だけ。同一origin扱い、親ページのDOM・保存領域、フォーム送信、ダウンロード、ポップアップ、上位ページ移動を許可しない。`srcdoc` に自己完結したscriptとstyleを入れ、CSPのhashを一致させる。通信・画像・フォント・別frame・objectは許可しない。親子の通知は実際の `contentWindow` / `parent` を照合し、表示サイズにも上限を設ける。

初期表示は停止。固定入力の再生は終端で止まり、自由な連続進行も12秒で止まる。画面外、タブ非表示、フォーカスを離れたとき、親の停止操作ではRAFを解除し、押下キーとpointerを消す。状態は保持し、戻るだけでは再開しない。閉じるとiframeごと破棄する。

「再生を1コマ」は固定入力を1/30秒だけ進めて止める。動きを減らす設定でも自動再生せず、1コマずつ比較できる。12秒の上限は実行量を抑えるための値で、酔い・健康・ゲームの面白さの安全基準ではない。
