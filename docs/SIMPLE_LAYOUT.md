# 明るい簡素な表示

2026-10-09の指示に合わせた `light-simple` ブランチです。

名前とナビゲーションの下に作品を並べます。装飾の立体、キャッチコピー、説明用の見出し、件数、空欄を埋めるための案内は表示しません。雑記には日付、本人の記事タイトル、分類を表示します。記事内の本人の見出しと文章は保持しています。

[maima.me](https://maima.me/) の公開HTML・CSSとブラウザ表示を確認し、白い背景、一定の幅、控えめな文字と余白を参考にしました。画像中心の作品一覧はコピーせず、手元の作品名とGitHubの説明を並べています。参考サイトのロゴ・画像・コードは取り込んでいません。

## プレビュー

```sh
LOCAL_WORKROOM=1 npm run build
python3 -m http.server 4370 --bind 127.0.0.1 --directory dist
```

`http://127.0.0.1:4370/` を開きます。このモードでは既に確認した6作品と既存記事1件を表示します。本文・プロフィール設定・画像設定・公開フラグは変更していません。通常の `npm run build` は引き続き `draft: false` の記事だけを対象にします。

## 記事の分類

記事の `category` に `ゲーム` と `感想` を追加しました。以前の `学び` と `雑記` も使えます。下書きエディタ、Markdown取込・出力、制作ログからの変換、検索URLが同じ選択肢を使います。

既存のCyberpunk2077記事は表示上の分類を「ゲーム / 感想」としました。元のMarkdownの分類と本文は変更していません。

編集入口と保存済みの続きは、フッターの「編集」を開くと使えます。主なページから比較案への入口は外し、既存の制作機能は専用ページに残しています。

## 確認

PC・375px・320px、キーボード、動きを抑える設定、JavaScript無効時をブラウザで確認しました。通常版とローカル閲覧版、それぞれルートとGitHub Pagesのサブパスでbuildと218件のテストが成功しました。下書き・編集用ページが通常の配布物に入らないことも確認済みです。lintはエラー・警告0件、既存コードのヒント3件でした。
