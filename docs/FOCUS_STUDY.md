# 一作品を開く・非公開比較

2026-10-04 UTC。Astraの独立批評で挙がった3点を、`/compare/focus/` に実装しました。既存ホーム、signal、collection、書く道具、検索のソースは保持しています。主案への採用と外部公開は本人の判断を待ちます。

## 変えた体験

1. 開いている作品の名前と確認済み説明を主役にしました。関連記録がある場合は、記事の見出し・説明・「記録を読む」を一つの読む面にまとめます。ない場合はGitHubのコードを開く導線で完結し、空の関連欄は作りません。
2. 作品選択を「他の制作を選ぶ」へ集約しました。選択後も同じ入口を残し、通常の切替ではスクロールしません。長い読み物の下で次の作品を開き、入口が画面外になる場合だけ、その入口へ即時に戻します。
3. 銀色の立体と接地影を、文字に遮られない独立した領域へ置きました。選択番号と黄緑の印が作品に対応します。番号は閲覧順であり、制作時期・成果・進捗ではありません。本文は同期的に切り替え、立体と印だけを220msで動かします。6番から1番への印は最短の62度を移動します。

動きを止める設定は既存の`archive-motion`を使い、再読込でも保持します。reduced-motionでは切替結果を静止表示します。無限アニメーション、新しい3Dライブラリ、外部素材は追加していません。

JavaScriptが使えない場合は全6件を続けて表示し、作品選択は通常のfragmentリンクで移動します。

## 情報の範囲

- 作品は[移植資料](MIGRATION.md)で確認済みの6件に限定し、既存のID・URL許可リストを使います。元の9件のMarkdownはすべて`draft: true`です。
- 作品名とGitHub API由来の説明をそのまま使います。説明のない作品には文章を補いません。日付・役割・本文・画像は表示モデルへ渡しません。
- [work-records.json](../src/data/work-records.json)は空のままです。関連付けを新たに確定していません。
- 関連記録は明示した関係があり、記事が`draft: false`かつ安全なIDの場合だけ表示します。抜粋にはその記事の`description`を使い、本文から要約を作りません。説明がない場合は抜粋も表示しません。
- 検証用の記事は隔離コピーにだけ置き、題に「表示検証用」、説明に合成の記録・本人の文章ではないことを明記しました。合成の関連付けも本体やリポジトリへ移していません。

- 全6作品をマウスとキーボードで選択。本文が同じイベント内で更新され、通常切替のscrollは0。選択番号・立体の番号・現在のリンク・本文・URLが一致し、再読込後も選択を保持しました。
- 長い読み物を模したブラウザ内だけの合成領域で、下部の「もうひとつ開く」を確認。1280pxではscroll 1418→100、375pxでは1355→121、320pxでは1356→121へ即時に移動し、切替入口と新しい内容が画面内に戻りました。
- reduced-motionと手動停止ではtransitionが0s、選択は即時に反映。手動停止は再読込後も保持しました。OS設定そのものや低性能実機の計測ではありません。
- JavaScript無効でも6件を読み、キーボードによるfragment移動が成立しました。ブラウザ内のrequestAnimationFrame待機はJS無効時に進まないため、検証側はホストから位置を確認しました。
- `/hamaya-site-draft`配下の合成関連記事へ移動し、戻った後も同じ作品・scroll 0を保持。検索語「合成」と分類「学び」はリロード・記事往復後も保持しました。
- 各画面幅で比較から書く画面へ進み、未保存の題・本文を入力。「読む」の内部・HTTPSリンクをクリック・Enter操作してもURLと入力は変わらず、「書く」へ戻って本文を保持しました。
- 実ブラウザは全9項目成功、pageerrorは0。lintは50ファイルでerror・warning・hintが0。
- 独立Astraが最終画像と操作記録を読み、読む階層・モバイルの往復・造形と選択の3点を合格と判定しました。追加の優先修正はありません。
- 通常12ページ、比較14ページをrootとproject baseでbuildし、各59テスト成功。合成記事の隔離fixtureは15ページ・59テスト成功。通常buildへ戻すと比較2ページは出力から消えます。

画像とJSONは作業領域の`.dot/focus-qa/`に保存しました。`browser-acceptance.json`が最終結果です。PlaywrightとChromiumは既存の一時領域を使い、サイトの依存関係やユーザーのブラウザ環境を変更していません。

## 再表示する

```sh

LOCAL_COMPARISON=1 npm test
npx astro preview --host 127.0.0.1 --port 4338
```

`http://127.0.0.1:4338/compare/focus/`を開きます。既存プレビューと並べる場合は独立コピーでbuildしてください。プロジェクト用baseはbuildとtestに同じ`BASE_PATH=/hamaya-site-draft`を指定します。

現在の確認用プレビューは`/tmp/hamaya-focus-qa-20261004/preview`の固定コピーをlocalhostだけで配信しています。本体は通常buildです。fixtureは`/tmp/hamaya-focus-qa-20261004/fixture`へ分離しました。

比較フラグは公開許可や認証を意味しません。Pages、公開workflow、外部deployは追加していません。
