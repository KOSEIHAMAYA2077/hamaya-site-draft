# 曲面と重なり — 統合版との比較

2026-10-04。`integrated-workroom` の `ac5bea09ff16ca4a9720b5977731404bb1d1a0e7` から、`.dot/site-contour` / `contour-study` に独立コピーを作りました。見た目を比べる一案です。元main・統合版・return-entry・持ち運び版はそれぞれ保持し、公開していません。

[同サイズの比較画像](contour-evidence/hamaya-contour-comparison.png) は、上段がPC 1280×812、下段が375×812です。各組で同じTypeAndSummon、同じ文章、同じ動き停止状態を撮影し、拡大縮小せずに並べています。Library保存IDは `libfile_2c87a0caee3c819193fa83be300852c1`、ファイルIDは `file_00000000d40c81f5a48f80ab53aae43a` です。

## 変えたところ

- **作品名と余白。** PCの作品名を約44pxから64px、375pxでは約23pxから33pxへ。モバイルは全幅で題を見せます。小さい「制作を開く」はそのまま画面の見出しとして使い、作品名を主役にします。
- **立体との重なり。** 基準版と同じ銀色のSVGを一つ使い、PCでは読む面の背後へ少し入れます。375pxは幅252pxの領域で穴と金属の厚みが分かる大きさにし、下端に読む面を重ねます。
- **読む面の曲率。** 片側の角を大きく曲げた白い面と、薄い灰緑の後ろ面を置きます。文字は平らな面に置き、立体が題・説明・ボタンを覆わないようにします。影と色は控えめです。

オフホワイトとグラファイトを保ち、緊張感は文字の大小・金属の明暗・面の重なりで作っています。新しい宣伝文句、ブランドのロゴ・素材、架空の制作情報は加えていません。

## 変更の範囲と検証

実装差分は `FocusStudy.astro` の比較用属性とCSS、`WorkroomHome.astro` からの指定だけです。操作スクリプト、立体SVG、作品データ、原文本文、packageとlockfileは基準版と同一です。新しい外部依存・描画ループ・アニメーション・認証・公開設定は追加していません。通常ホームや既存の `/compare/focus/` にはこの比較用属性を付けません。

ブラウザでは4幅・全6作品の文字とリンクが基準と同一であること、キーボード選択、Escape、次作品、hash再読込、書く画面への移動と未保存入力、停止設定、reduced-motionを確認しています。長い作品名でも横はみ出しや操作の遮りはありません。

実ブラウザは11検査群が成功しました。JavaScriptなしの初期主導線下端はPC 565.8px、375px 702.6pxです。動きON・OFFそれぞれの1.1秒のアイドル中に追加のrequestAnimationFrame呼び出しは0。外部通信・console/page errorも0です。

通常root・base付き通常・比較・workroomの4buildが成功し、各175テストが通りました。ページ数は5・5・15・23。lintはエラー0・警告0、既存の互換APIのhintが1件です。保護15ファイルのSHA-256、既存12worktreeのHEADとclean状態、元mainが不変であることも確認しました。

検証の数値と結果は [contour-evidence](contour-evidence/) に保存しています。測定はChromium 153のローカル実ブラウザで、375pxはviewportを指定した確認です。低性能の実機での性能測定とは分けています。採用と公開は本人の判断を待ちます。
