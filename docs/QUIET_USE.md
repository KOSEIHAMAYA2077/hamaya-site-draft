## 操作と失敗時の表示

- 実験は画面外・ページ非表示・履歴移動で進行を止め、戻るだけでは再開しません。方向キー、ボタン、1コマ進行、再生にも同じ可視条件を使います。
- Canvas初期化失敗は即時に、実行コードがCSPで止まった場合は6秒で、静止図と再試行へ戻ります。準備中も静止図を残します。
- 検索条件、関連記事への移動、Back、再読込、0件の表示、キーボードでのFocus選択を確認しました。日本語の変換確定前は結果を切り替えません。
- 320pxの長文／多画像／一覧、375pxの実験に加え、JavaScript無効時の本文・リンク・静止図を確認しました。
- 4倍のCPU制限をかけたChromiumでも操作を確認しました。実在する低性能端末の代用とは扱いません。
- Focusと実験の静止画は、遷移完了後の前後比較で画素差0でした。説明・導線・余白は維持しています。

実験ブラウザ回帰は12ブロック成功。通常のJavaScriptエラー・通信失敗は0件です。CSP不一致の1件は意図した失敗fixtureとして別記録です。モデル4ファイルは元のSHA256と一致しています。

headlessブラウザでは別タブを前面にしても `document.hidden` が変わらず、実タブのバックグラウンド化は再現できませんでした。非表示イベントの合成試験では停止しました。履歴の往復は確認しましたが、`pageshow.persisted` がfalseだったためBFCacheによる復帰自体は未確認です。
