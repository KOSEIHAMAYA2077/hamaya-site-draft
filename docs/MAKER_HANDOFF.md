# Maker Fieldから、サイトの下書きへ

Maker Fieldで残した制作ログ・比較・実験・アイデアから1件を選び、記事のMarkdownをダウンロードできます。本人のファイルはまだ使わず、合成入力で確認したローカル限定の道具です。

## 使い方

1. Maker Fieldの「データを持ち出す・戻す」（狭い画面では「データ」）を開き、「JSONを書き出す」を押します。
2. [下書き接続のローカル画面](http://127.0.0.1:4354/hamaya-site-draft/write/maker-field/)でJSONを選び、件数を確認して「このJSONを開く」を押します。残したい1件を選び、短い要約・分類・ファイル名を入力します。
3. 「下書きを確認」→「下書きをダウンロード」。続けて「書く画面で確認する（別タブ）」を開き、「Markdownを取り込む」で保存したファイルを選びます。既に入力がある場合は「このファイルで置き換える」を確認して押します。「読む」で内容を確認できます。

サイト内では、ローカル画面下部の「制作ログを下書きに（別タブ）」と「書く」の上部からも入れます。既存の執筆タブは別に残るため、未保存の文章へ戻れます。既存タブへ取り込む場合も、確認して開くまでは元の入力が残ります。

このURLは同じMac上で確認サーバーが動いている間だけ使えます。公開URLではありません。

## 残るものと、変わらないもの

- 出力は必ず `draft: true` の記事1件です。タイトル・日付・タグを引き継ぎ、要約・分類・ファイル名は本人が決めます。題や日付の未入力は補完しません。
- HTML・リンク記法・長い日本語は文字として確認でき、出力本文ではコード枠に保存します。画像本体は含めず、省略した項目・サイズ・SHA-256を残します。原JSONは別に保管してください。
- 元のJSON、Maker Fieldの保存領域、サイトの記事ファイルは書き換えません。サーバーへの送信、クラウド保存、公開処理はありません。
- 入力はこのタブのメモリだけに保持します。記録を選び直すと各記録の要約・分類・ファイル名が戻ります。別JSONを開くと確定した場合、読み込みをやめた場合、またはページを閉じた場合に消えます。
- JSON選択の取り消し・置き換えの取り消し・読み込みエラーでは、現在の記録と入力を保持します。同じ画面で一度ダウンロードした名前は再使用を止めます。端末に既にあるファイル名は調べません。保存先や同名ファイルの扱いはブラウザで確認してください。

## 独立した実装と利用条件

枝は `maker-field-handoff`、基点は `quiet-use-quality` の `739bcdbcabaa2ef3dcda077ced41e2821634efd8` です。元Maker Fieldと完成アダプターを読み取り、ブラウザに必要な変換処理だけを `src/maker/` に独立実装しています。元アダプターや元アプリは実行・変更していません。

元配布にはLICENSE/NOTICEの記載を確認できませんでした。ユーザー依頼の非公開接続として扱い、新しいライセンスを付けていません。元ソースの実測SHA-256と差分は [source-manifest.json](../src/maker/source-manifest.json)、制限とAPIは [src/maker/README.md](../src/maker/README.md) に記録しています。追加の第三者依存はありません。

通常の `npm run build` では、この画面・入口・変換処理・取り込み用YAML解析処理は出力されません。開発時または既存ローカル用build設定のときだけ含まれます。画面の操作はloopbackホストに限ります。認証や公開配信の仕組みではないため、ローカル用buildをそのまま公開する用途には使いません。

## 検証記録

合成の長い日本語・HTML記法・画像項目を含むJSONから、354,808 bytesのMarkdownを実際にダウンロードし、既存の「書く」へ取り込み、再ダウンロードした本文とfrontmatterの完全一致を確認しました。`draft: true` を保持します。

JSONの重複ID・エスケープを含む重複キー・未知項目・不正UTF-8・単独サロゲート・容量超過、空状態、題や日付の未入力を確認しています。320px・キーボード・reduced motion・JavaScript無効でも表示を確認しました。OSのファイル選択ダイアログの取り消しは、ブラウザ内のcancelイベントで検証しています。

自動テストでは8 MiB入力・1 MiB出力・64 KiB frontmatter・画像1 MiBの境界、全既知項目、非同期変換中の入力変更、完成アダプターの合成出力との固定ハッシュ比較を含みます。

最終lintは0エラー・0警告・0hint。通常root、`BASE_PATH=/hamaya-site-draft` の通常版、同baseのローカル比較＋実験版で各149テスト成功しました。通常版は5ページ、ローカル比較＋実験版は16ページです。

実ブラウザはChrome 153で27確認項目が成功しました。ログ別の入力復元、空選択からの復元、新JSON確定時の消去、遅い変換が新しい選択を上書きしないことも含みます。観測した39通信はlocalhostへのGETだけで、原文の送信・外部通信・保存領域への書き込み・予期しないスクリプト実行・ブラウザエラーはありませんでした。

[検証結果](maker-handoff-evidence/validation.json)・[ブラウザ記録](maker-handoff-evidence/browser-evidence.json)・[画面画像](maker-handoff-evidence/hamaya-maker-handoff.png)を保存しています。Library画像IDは `libfile_6a308a5c8e988191915c18ab3b26bcb0` です。確認用の合成データは `maker-handoff-evidence/generate-fixtures.mjs` から生成でき、本人の制作物は含みません。
