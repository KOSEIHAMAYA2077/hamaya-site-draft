# 実験ページの出典とコピー範囲

「実験を見る」は、本人が採用を考えるための非公開・ローカル限定の比較ページ。今回のユーザー指示に基づき、`game-kernel-lab` から必要最小限の独立コピーを作る。本人の完成作品や公開実績としての採用は未確定であり、通常の公開用 build には含めない。

## 制作の役割

選んだ2つは、依頼に沿ってAIが実装・検証した小試作。原本の制作記録はAIの提案・実装、動作検証、本人による試遊や評価を区別している。対象ディレクトリを追加したGitコミットの作者表記は `Codex`。

画面では「シド（AI）の試作」とし、本人の制作物一覧とは分ける。本人の単独制作、採用済み作品、理解や面白さの評価が済んだ成果とは表示しない。今回のサイト用UIと説明もAIによる試作として扱う。

## 素材と依存

原本の `package.json` は `private: true` で、外部パッケージの依存宣言はない。選択したモデルにはimport、ネットワーク接続、ブラウザ保存領域、画像・音声・フォントの参照がない。テストの依存は `node:test`、`node:assert/strict` と各モデルだけ。

元UIもCanvasの矩形・円・線とシステムフォントで描画され、既成キャラクターやアニメーション素材を使わない。サイト側は別の小UIと図形を用意するため、第三者の画像・音・フォント・モデルは追加しない。

原本のBRIEFは、[Wolfire公式 `aschar.as`](https://github.com/WolfireGames/overgrowth/blob/main/Data/Scripts/aschar.as) の `HandleAccelTilt` を着想元として記録している。今回も対象関数を読取り、速度と速度差から姿勢の目標を作る処理を確認した。

原本の2Dのばね・減衰、係数、荷物の遅れ、比較方法はラボ独自の実装と明記されている。モデル内の該当処理も確認し、公式関数のコードをコピーする構成ではない。Wolfireのソースファイルや素材は今回のコピーに含めない。

[公式README](https://github.com/WolfireGames/overgrowth#license)、[LICENSE](https://github.com/WolfireGames/overgrowth/blob/main/LICENSE)、対象コードのヘッダーを実読し、コードがApache-2.0であることを確認した。原作素材の配布には別途明示許可が必要という記載もある。今回は参考元へのリンクを残し、原作のコード・素材の採用としては扱わない。

### G：移動と時間を結び付ける考え方

原本のBRIEFは、[SUPERHOTチーム公式紹介](https://superhot.itch.io/superhot)を着想元として記録している。今回も公式紹介の移動と時間の説明を読んだ。
