# Maker Fieldの下書き接続

ユーザー依頼の非公開接続として、独立した変換処理を用意しました。元のMaker Fieldと完成アダプターは変更せず、JSON全体を検証し、選択した1件を常に `draft: true` の記事へ変換します。

## API

- `parseMakerField(bytes: Uint8Array)` は同期処理で、検証した `{ version, logs, experiments, ideas }` を返します。
- `await convertMakerField(bytes, { collection, id, slug, description, category })` は `{ filename, markdown, report }` を返します。`category` は `学び` または `雑記` です。
- `RECORD_FIELDS`、`LABELS`、`COLLECTION_LABELS`、`MAX_INPUT_BYTES` を画面から参照できます。

Node.js 24以上とブラウザの標準APIを使います。SHA-256にはWebCryptoが必要です。Nodeのimport、CLI、ファイル操作、通信、localStorage、DOM操作は含みません。既存の `../lib/draft-export.mjs` を再利用します。ダウンロードや取り込み操作は画面側の責務です。

ファイルはバイト列で渡してください。不正UTF-8を置換する `File.text()` は使用せず、`arrayBuffer()` と `Uint8Array` を使います。変換開始時に入力バイト列と設定を保持するので、非同期ハッシュの途中で画面の選択が変わっても、出力の選択内容は変わりません。画面側でも古い変換結果の表示を防いでください。

## 入力と出力の境界

| 対象         | 上限・条件                                                  |
| ------------ | ----------------------------------------------------------- |
| JSON         | UTF-8で8 MiB。BOMは除去を報告。不正UTF-8は拒否              |
| 構造         | 深さ32、25万値、objectのキー200、キー長200、各配列5000      |
| 文字列       | 4 Mi UTF-16単位。単独サロゲート・禁止制御文字を拒否         |
| 記録         | 3種類で合計5000件。同じ種類内の重複IDを拒否                 |
| ID・題       | IDは1〜160文字、題は240文字以内。文字数は元仕様のUTF-16単位 |
| タグ・関連ID | タグ100件×40文字、関連ID5000件×160文字。順序・空文字を保持  |
| 画像         | 空、またはPNG/JPEG/WebPのbase64。復号後1 MiB以内            |
| Markdown     | UTF-8で1 MiB、frontmatterはUTF-8で64 KiB以内                |

元の検証規則に加え、JSONの同名キーは解析前に拒否します。`"body"` と `"\u0062ody"` も同名です。未知項目、危険キー、不正な型や日付は、選択外の記録を含む入力全体で検査します。空の日付は読み込めますが、選択した記録の書き出しには題と実在する日付が必要です。補完はしません。

題・日付・タグはfrontmatterへ引き継ぎ、要約・ファイル名・記事種別は明示した設定を使います。それ以外の既知項目は文字としてコード枠に配置し、HTML・Markdown記法・関連IDを実行要素やリンクへ変換しません。コード枠は入力中の連続バッククォートより長くします。CRLF/CRはLFへ揃え、空文字・空配列・falseは保持します。

既存のMarkdown単独出力では画像本体を出力せず、復号したバイト数とSHA-256、省略した項目を本文と報告に残します。この経路では画像デコーダによる内容検査やプレビューは行いません。元JSONはバックアップとして別に保管する必要があります。

## 画像も持ち出す

「下書きを確認」のあと、「画像と一緒に持ち出す（ZIP）」を押します。ZIPを展開すると、選んだ1件の `.md`、最大2枚の `images/` 配下の画像、`report.json` が得られます。Markdownとimagesフォルダーを一緒に移してください。書く画面には展開したMarkdownを明示的に選びます。

`portable.mjs` の `createMakerPortablePackage(bytes, options)` は、全ファイルをメモリー内で準備してから `{ filename, markdown, markdownFilename, report, bytes, files }` を返します。元の変換処理を再利用し、画像の節だけを `./images/<slug>-before.png` などの相対参照へ変えます。その他の文章・設定は既存の変換と同じです。既定の `convertMakerField()` の結果は変えていません。

PNG・JPEG・WebPの宣言と先頭形式を確認し、ブラウザの `createImageBitmap` で実際に読み取れることを確かめます。復号後の縦横は8,192px以内、合計16,777,216画素までです。PNGはヘッダー寸法も復号前に確認します。画像バイトは再エンコードせずそのまま同梱し、サイズ・SHA-256・寸法・相対パスをreportへ記録します。実際に読めない画像・対応しないブラウザ・未知の設定・上限超過ではZIPをダウンロードせず、画面入力を残します。

`stored-zip.mjs` は依存のない少数ファイル用のZIP（無圧縮STORE形式）です。最大4ファイル、各1 MiB、全体4 MiB以内。ASCIIの相対ファイル名だけを受け付け、重複・親ディレクトリー参照・絶対パス・予約名を拒否します。日時は固定値で、現在時刻やブラウザ情報を記録しません。

ZIPには選択外の記録・関連ID先・元JSONを含めません。元のJSON全体を復元するためのバックアップは別に保管してください。BOM除去や改行の正規化はreportにも残ります。API単体テストのデコーダー差し替えは構造検査用で、実画像の読み取りはブラウザ検証で確かめます。

## 由来とライセンス

[source-manifest.json](source-manifest.json) に、読んだ元コードと契約の実測SHA-256、既存サイトとの一致、独立実装の変更範囲を記録しています。元のCLI、VM、Maker Field保存処理は取り込んでいません。第三者ランタイムのコピーや依存の追加もありません。

**元配布LICENSE記載なし・新ライセンス付与なし・ユーザー依頼の非公開接続**です。元アダプター配下にLICENSE/NOTICEは確認できませんでした。出典記録を再配布許諾と解釈せず、既存コードへ別のライセンスを付けていません。
