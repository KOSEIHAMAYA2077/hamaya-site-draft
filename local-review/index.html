配布版の場所と起動手順

Library内の MAKER-FIELD-20261004.zip が配布版です。保存ID: libfile_caabd1ee7a5c8191b8303e1b05a5ae81

このMacでは task-6/maker-field-release-20261004/ にあります。既定の4187は別コピーが使用中なので、配布版へのリンクにはしていません。

配布フォルダを開き、4188が空いていることを確認して PORT=4188 node server.cjs。起動後に http://127.0.0.1:4188/ を開きます。これは起動例で、今このポートでの稼働確認はしていません。

保存はブラウザとポートごとに別です。別コピーのデータを自動共有せず、専用JSONもそのままサイト記事にはなりません。詳しい保存先と形式の違いは docs/COMPARISON_GUIDE.md にあります。

各カードのコードは画像撮影元の参照です。現在の試用先とは別で、保存画像との全ファイル一致は候補画面を除き未照合です。

画像は撮影時に動いていたプレビューの記録です。主案に入っていない下書きや、合成の検証用記事を公開した状態にはしていません。画面の案内文・図形はUIの試案で、本人の文章や実績として確定したものではありません。

表示の確認範囲と起動について

7案の試用リンクは、このMacで動く統合候補の対応画面です。保存画像の撮影時はすべてHTTP 200。画像の撮影元と参照コードは各カードに記録しています。現在の試用画面には、その後の変更も含まれます。

ブラウザで表示を確認しましたが、本人が使った評価はこれからです。スクリーンショットは静止状態です。制作物の実行成功・作者・制作期間の証明には使いません。

ガイドの起動は専用コピーで npm run guide。保存時の起動手順は同じコピーの docs/COMPARISON_GUIDE.md にあります。旧試用サーバーは停止し、現在の入口はページ冒頭にまとめています。開いた別タブは確認後に閉じて、このガイドへ戻れます。

このガイド・画像・操作コードは通常のサイトbuildへ含めません。Library版のlocalhostリンクも同じMacでのみ開けます。
