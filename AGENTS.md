# Site draft boundaries

- This checkout is the independent draft. Do not modify an existing public site or repository.
- Keep this repository private. Do not enable Pages, deploy workflows, public hosting, or new authentication without the user's request.
- Keep private email, financial information, nonpublic work materials, internal notes, and credentials out of the content and repository.
- Profile claims, selected works, AtCoder links, portraits, and migrated articles require owner-confirmed content. Do not invent details.
- All new content starts with `draft: true`. Only entries explicitly set to `draft: false` appear in generated pages.
- Verify `npm run lint`, `npm run build`, `npm test`, and the project base-path build when changing routes or content behavior.
- Use Japanese navigation and concise natural copy. Honor reduced motion, keyboard access, and mobile layout.
